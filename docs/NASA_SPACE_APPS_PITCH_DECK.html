01 • THE CHALLENGE 02 / 07

When Earth is Out of Reach: Deep Space Transit Risks

Cloud-native telemedicine fails past Low Earth Orbit due to unavoidable physical and operational constraints.

Speed-of-Light Latency

Mars transit introduces 3 to 22+ minutes of one-way delay (up to 44 min round-trip). Interactive ground doctor consultation is physically impossible during acute triage.

Loss of Signal (LOS)

Planetary occultation, solar conjunctions, and high-gain antenna maneuvers cause complete multi-day communication blackouts. Systems cannot rely on live cloud connections.

Microgravity Hazards

Headward fluid shifts induce SANS (Spaceflight-Associated Neuro-ocular Syndrome), cosmic ionizing radiation requires instant dosimetric tracking, and cardiovascular deconditioning escalates.

DESIGN QUESTION:

How can an astronaut crew monitor, record, triage, and review multi-system biometric telemetry without depending on a continuous link to Earth?

04 • TECHNICAL ARCHITECTURE 05 / 07

Engineered for Harsh, Disconnected Environments

A hardened PWA runtime backed by client-side storage and idempotent cloud synchronization.

Client-Side Architecture

  • UI Framework: React 18, TypeScript, Vite, TailwindCSS.
  • Offline Runtime: Workbox Service Worker precaching entire application shell and assets.
  • Local Storage: IndexedDB via Dexie.js managing vitalsQueue, checkins, and imagingAssessments.
  • 3D Graphics: Three.js canvas optimized for low CPU/GPU power consumption.

Backend & Cloud Sync

  • FastAPI Gateway: High-throughput local REST API serving baseline calibrations and diagnostic engines.
  • Cloud Target: Supabase PostgreSQL with Row Level Security (RLS) for multi-crew mission isolation.
  • Idempotent Replay: Unconfirmed queue transmission receipts; records deleted only upon verified sync.
  • Voice Pipeline: Web Speech API live stream + Groq Whisper Large-V3 Turbo.

✓ VERIFIED RELIABILITY: 40 of 40 automated unit tests passing across storage quotas, sleep calculations, and data isolation boundaries.

Clinical Governance & Safety Boundaries

BioTelemetry does not diagnose or replace Flight Surgeons. All AI evaluations state probabilistic confidence, simulated demo measurements are strictly watermarked, and private reflective notes are excluded from telemetry downlinks.
